BOOTSTRAP 5 WEBSITE ASSIGNMENT
==============================

This folder contains five separate HTML/CSS pairs:

1. startup-landing-page.html / startup-landing-page.css
2. personal-portfolio.html / personal-portfolio.css
3. product-catalog.html / product-catalog.css
4. restaurant-menu.html / restaurant-menu.css
5. themed-blog-homepage.html / themed-blog-homepage.css

HOW TO RUN
----------
1. Extract the ZIP file.
2. Keep each HTML file next to its matching CSS file.
3. Open any HTML file in a modern browser.
4. Internet access is required for Bootstrap 5 CDN, Google Fonts, and remote images.

NOTES
-----
- Bootstrap 5.3.3 is included via CDN in each HTML page.
- No JavaScript is used; these layouts do not require interactive Bootstrap JS components.
- The portfolio CV link is a placeholder to a local file named cv.pdf. Add your own CV with that filename if needed.
- Portfolio contact details are example placeholders; update them before publishing.
- Product cart buttons are visual demo links, not a working shopping cart.
- All pages use semantic HTML5 structure and responsive Bootstrap grid/flex utilities.
